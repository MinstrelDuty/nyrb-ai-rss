# Obsidian 导出与全文检索设计

日期：2026-07-04

## 目标

在不增加后端服务和构建步骤的前提下，为现有静态书评页面增加：

1. 当前刊物与全部四刊的全文检索。
2. 每期单文件 Markdown 下载。
3. 当前刊物 ZIP 归档下载。
4. 全部四刊 ZIP 归档下载。

导出结果应适合直接解压到 Obsidian Vault，并保留来源、日期、原文链接等元数据。

## 非目标

- 不修改 RSS 生成脚本及其更新机制。
- 不增加服务端数据库或搜索服务。
- 不实现模糊搜索、中文分词或相关性学习。
- 不改变现有文章阅读卡片的主体视觉风格。

## 方案选择

采用浏览器端按需加载和原生子串匹配。当前数据规模有限，原生匹配对中英文标题、作者、摘要及正文都可靠，且避免额外搜索依赖。压缩归档复用 JSZip，HTML 转 Markdown 复用现有 Turndown。

未选择 Fuse.js，因为错字容忍对当前需求不是核心，中文排序收益有限。未选择预生成搜索索引，因为会增加 Actions 与数据同步复杂度。

## 数据模型与加载

页面维护四刊配置表，包含刊物标识、显示名与 XML 文件名。XML 解析统一输出标准文章对象：

- `sourceId`、`sourceName`
- `titleZh`、`titleEn`
- `metaInfo`、`hook`
- `contentHtml`、`contentText`
- `link`
- `publishedAt`、`dateKey`

当前刊物切换时加载对应 XML。选择“全部四刊”检索或下载全部归档时，使用 `Promise.allSettled` 加载其余 XML，并缓存成功结果，避免重复请求。

## 全文检索

页头增加搜索框、范围切换按钮和结果计数：

- “当前刊物”：仅搜索当前标签页对应数据。
- “全部四刊”：搜索四份 XML 的缓存数据。

匹配字段包括中英文标题、作者与对象、破题、正文纯文本。输入按大小写不敏感的子串匹配处理，空查询恢复普通刊物视图。输入采用短延迟防抖。

搜索结果按发布日期倒序展示，卡片增加刊物与日期标识，并在标题、元信息、破题和正文摘要中高亮匹配词。高亮前必须转义用户查询和文本，避免将查询内容作为 HTML 执行。

全部检索中若部分 XML 加载失败，展示非阻断提示并保留成功来源的结果。

## Markdown 导出

### 单期下载

现有“下载本期 (html)”替换为“下载本期 (.md)”。一个文件包含当期所有文章，顶部为刊物与日期标题，每篇文章包含标题、元信息、破题、正文和原文链接。

### ZIP 归档

页头增加两个操作：

- 下载当前刊物归档
- 下载全部四刊归档

ZIP 结构：

```text
书评深度集萃/
  README.md
  NYRB/
    2026-07-02/
      01-文章标题.md
  LRB/
  TLS/
  NYT/
```

每篇文章独立成 Obsidian 兼容 Markdown，包含 YAML frontmatter：

```yaml
---
title: 中文标题
original_title: English Title
source: NYRB
published: 2026-07-02
original_url: https://example.com/article
tags:
  - 书评
  - NYRB
---
```

正文中的 HTML 使用 Turndown 转换为 Markdown。文件名移除 Windows 与 ZIP 不允许的字符，限制长度，并使用序号避免同名覆盖。YAML 字符串使用安全转义。

根目录 `README.md` 说明生成时间、来源、文章数量和目录结构。若某刊加载失败，其错误写入 README，ZIP 仍包含其他成功来源。

## 交互与错误处理

- 下载期间禁用对应按钮并显示“正在整理…”。
- 下载完成或失败后恢复按钮文字与可用状态。
- 缺少 JSZip 或 Turndown 时给出明确错误，不生成不完整文件。
- 单期无文章、当前刊物未加载或全部来源均失败时不启动下载。
- Blob URL 在触发下载后及时释放。

## 依赖策略

- JSZip 固定到明确版本的 CDN URL。
- Turndown 改为固定版本 URL，避免浮动依赖改变行为。
- 保持当前纯静态 HTML 部署方式，不引入 npm 构建产物。

## 测试与验收

先为可测试的纯函数建立失败测试，再实现：

- 文件名清洗与重复名处理。
- YAML 转义与 Markdown frontmatter。
- HTML 到 Markdown 的文章结构。
- 当前刊物与全部四刊的字段匹配。
- 空查询、特殊正则字符和中文查询。

浏览器验收覆盖：

1. 页面正常加载且无相关控制台错误。
2. 当前刊物检索只返回当前来源。
3. 全部四刊检索返回带来源标识的结果。
4. 清空查询恢复普通视图。
5. 单期 `.md` 下载文件名及内容正确。
6. 当前刊物 ZIP 与全部四刊 ZIP 均可生成，目录和 YAML 正确。
7. 桌面与移动视口中搜索框和下载按钮无溢出或遮挡。

## 完成标准

- 页面仍可由 GitHub Pages 直接托管。
- 用户无需安装扩展即可完成检索和下载。
- ZIP 解压后可直接放入 Obsidian Vault 使用。
- 现有四刊浏览、文章展开和原文链接行为不回归。
